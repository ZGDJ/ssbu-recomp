# Smash Ultimate setup

You need the **three ZIP files I sent**, internet, a Windows 64-bit PC and about **30 GB free in addition to the ZIP files**. Allow an hour or longer for installation.

**1. Create your game folder**
- Go to your Desktop.
  - Right-click an empty space → **New** → **Folder**.
  - Type **Smash Ultimate** → press **Enter**.

**2. Put the downloads in that folder**
- Open **Downloads** in File Explorer.
  - Select the **OpenSmash-Family** installer ZIP, **Smash-Ultimate-13.0.5-OpenSmash.zip**, and **Smash-Ultimate-Completion-Save.zip**.
  - Right-click → **Copy**.
  - Open **Desktop → Smash Ultimate** → right-click an empty space → **Paste**.
- Leave the game ZIP and save ZIP compressed.

**3. Extract ONLY the installer ZIP**
- Right-click the **OpenSmash-Family** ZIP → **Extract All…**.
  - In the window that appears, click **Browse…**.
  - Select **Desktop → Smash Ultimate** → **Select Folder**.
  - Click **Extract** and wait for it to finish.
- Open **Desktop → Smash Ultimate → OpenSmash**.
  - You should see **Install OpenSmash.bat**. Windows may hide the `.bat` ending.

**4. Install the game**
- Double-click **Install OpenSmash.bat**.
  - A file-selection window should open.
  - Go to **Desktop → Smash Ultimate**.
  - Select **Smash-Ultimate-13.0.5-OpenSmash.zip** → click **Open**.
- A setup window will show progress. **Keep it open and keep the PC awake.** This can take an hour or longer.

**5. Apply the completion save (optional)**
- After the build, an **Optional save import** popup appears.
  - To use the completion save, click **Yes**.
  - In the file-selection window, go to **Desktop → Smash Ultimate**.
  - Select **Smash-Ultimate-Completion-Save.zip** → click **Open**.
  - Click **OK** when it says the save was imported.
- Choose **No** if you want to start fresh or keep your existing progress.
  - Importing replaces current progress, but keeps a backup of the previous save.

**6. Play**
- Click **OK** when setup reports completion. Close the setup window when prompted.
- Go to your Desktop → double-click **OpenSmash Play**.
  - First launch prepares shaders and may take several minutes.
  - **Z** confirms prompts. **F1** opens settings.
- Keep the **Smash Ultimate** folder in its original location. Do not move or delete its **OpenSmash** folder.

**Get updates**
- Close the game → double-click **Update OpenSmash** on your Desktop.
  - Leave its window open until it finishes. Your saves and settings stay in place.
  - If interrupted, run **Update OpenSmash** again.

**Import the save later**
- Close the game → open **Desktop → Smash Ultimate → OpenSmash**.
  - Double-click **Import Save.bat** → **Yes** → select the completion-save ZIP → **Open**.

**If anything fails:** stop and send me the error message or a screenshot. Do not delete your game folder or disable security software. GameCube adapters may need a separate WinUSB driver; ask me if your controller is not detected. This is an experimental build, and online rollback is still being worked on.
