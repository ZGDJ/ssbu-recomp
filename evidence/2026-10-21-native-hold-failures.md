# Native hold failure hardening

2026-10-21. Follow-up to the [live command-buffer refusal audit](2026-10-21-live-command-buffer-refusal-audit.md). M7.8 remains in progress. Root owns ring integration and validation; a separate implementation agent owns native hold handling and tests; an independent reviewer checks the lifecycle.

## Finding and change

Source inspection found that failed `SuspendThread` calls in capture and restore could break a polling loop without marking the operation unsuccessful. Capture could then publish an incomplete hold set, and restore could reach mutation without holding a required thread. Owned releases also ignored `ResumeThread` results before clearing bookkeeping.

Capture now refuses on a required suspension failure and releases both accepted holds and any outstanding all-first pre-suspensions. Restore records a distinct hold failure; the ring checks it immediately, before quiet retries or state preparation, and follows its refusal cleanup. Successful suspend/resume behavior is preserved. A release returning zero or failure cannot establish that this owner released a suspension: execution stops with diagnostics before clearing the caller's ownership flag. Legacy restore callers without a recoverable refusal contract stop on hold acquisition failure.

The ring still distinguishes transferred capture holds from additional holds on newly created threads. Snapshot records clear `held` and `cok`; they cannot manufacture current ownership. Refusal releases the current set and the separate born-thread journal, then restores prior inventory with all ownership flags cleared. The success path's inherited policy of leaving newly created threads suspended is unchanged and remains a continuation-completeness limitation.

## Remaining scope

This fixes API failure propagation and checked release behavior. It does not establish native continuation equality, writer quiescence, complete thread enumeration, fresh-fiber recovery, or balanced ownership across every external thread user. The planned native-state refusal observer remains next, alongside localization of any repeated page-plan refusal using the new counters. Earlier incomplete observations and replay-state divergence remain open; no gameplay or online qualification follows.
