# Family setup wizard

- Date / author: 2026-10-21 (America/New_York), Codex. Local source review and rendered-window inspection; no independent review.
- Task / requirements: M0.8, FSD-011 and FSD-012. Source-only and native UI fixture validation. M0.9 remains open.
- Baseline: `46a8f6c`; isolated branch `fix/family-setup-wizard`. Only installer source, tests, instructions and related evidence/ledger are included. Uncommitted runtime changes in the primary checkout are excluded.
- Behavior: Install OpenSmash opens a Windows Forms wizard without requiring Python first. It explains the permanent folder, game ZIP and requirements; launches the existing worker with noninteractive completion/error handling; displays a marquee activity indicator and bounded live log; exposes Retry after failure and Play instructions after success. The running window refuses ordinary closure to avoid abandoning installation. The worker retains its existing installation mutex, archive validation and resumable data/build behavior.
- UTF-8/path fixes: see [encoding/path evidence](2026-10-21-installer-encoding-paths.md). The wizard passes Unicode/spaced/quoted paths using PowerShell EncodedCommand, reads UTF-8 worker output, and retains the process handle so fast process exit codes remain available. OutputFormat Text avoids serialized CLIXML in the user log. Setup logs are retained under build/logs.
- Validation command: `python -m unittest discover -s tests -p 'test_family*.py' -q`, using the development Python 3.12 on Windows. Native wizard tests use a disposable worker, no downloads or real game data. Result: 25 tests passed, exit 0, including failure/retry/success, close guard, activity indicator, Unicode output, archive preflight, resumable import and update preservation. `tools/check_project_docs.py` and `git diff --check` also passed.
- Render inspection: `tests/family_wizard_smoke.ps1` rendered the actual Windows Forms window to an ignored PNG. Instructions, controls and log are readable without overlap at the tested desktop scale. No claim for every DPI/monitor configuration.
- First failures: the initial native test caught missing ExitCode after process termination. Retaining the process handle fixed it; the synthetic failure then reported 1 and retry reported 0. The encoding/path follow-up records earlier sandbox restrictions separately.
- Artifacts: disposable fixtures and UI preview under ignored artifacts/local; no private data in this evidence. Packaging uses the existing committed-source packager and checksummed ZIP format. No GitHub publication or update-channel change is part of this work.
- Limits: this is a guided source installer, not an MSI or bundled game executable. The animated bar indicates a live worker, not guaranteed forward progress or remaining time. Large-file byte progress updates when copying advances. Bootstrap errors may still show the bootstrap helper's own error dialog. A real clean-PC install and two-revision update remain M0.9 acceptance work.
- Handoff: distribute the newly committed source ZIP for fresh setups. Existing successful/running installations need not restart or have a new archive overlaid on their data.
