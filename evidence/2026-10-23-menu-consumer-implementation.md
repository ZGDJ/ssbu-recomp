## Decision and scope

The completed baseline/+60 contrast has equal global vectors at menu begin and different vectors at confirmation. Faithful selector/owner/reset propagation does not support a seed/reset correction. This observer tests one bounded alternative: whether original helper `0x710137bc30`, called with the specific global `0x71052391c0`, executes during that interval and which original callers/ranges it observes. The known six-element permutation is a candidate, not an assumed executed owner. Inline and other uncovered consumers exist.

Exact setting `SSBU_RNG_MENU_CONSUMER_PROBE=1` requires the existing validated menu/origin/reset/early and dedicated trace/hash prerequisites. Other setting values install nothing. The hook requires one non-null function-table match and reads the complete 0x600-byte helper window through the existing checked read before attachment. Target `0x710137bc30`, FNV `18fa160f0255f52b`, window SHA-256 `e307687efd4503b8122ff02a79f5b292156cfcc4d25a50391c294a2b1a873d69`. Independently extracted private ELF SHA-256 is `c81f5bb377783ec32468f9ee97c4c01bdf2c3dd84bb7fd8d94c9756360989045`. The window ends immediately before `0x710137c230` and includes the original helper's trailing padding. Missing/duplicate/version/read/fingerprint/attachment/original-pointer failures are fatal and fail closed.

Entry x0 selects the global; original x1 points to two 64-bit range bounds. Entry LR, original descriptor address/bounds, sequence ticks/thread, before/after four-word vectors and returned x0 are captured. The original helper always runs once, even when observation fails; no guest argument/state patch or execution lock is introduced. LastError is restored before the original and its post-call value restored after diagnostic work. Original register changes remain intact. Range equality, full-width and rejection paths mean invocation counts are not recurrence counts.

## Lifecycle and integration contract

The new header is included after `rng_menu_probe.h`, with static prepare/boundary/unusable prototypes declared before that header. Root calls start immediately after menu start. Root publishes each existing sequence tick using `fight_rng_menu_consumer_tick` immediately after the existing counter increment; publication uses interlocked operations. Hook threads never read plain `g_seq_polls` or plain menu state. Startup alone checks existing menu prerequisites on the owning startup path.

Menu prepare brackets the existing checked sample: prepare immediately before the read, finish after the validated sample is logged and before the menu state update. A menu failure notifies the consumer. Atomic observer states distinguish waiting, opening, open, closing, sealed and unusable. Every target-pointer call increments an active counter even outside the open interval, preventing an original call spanning the opening/closing sample from being silently omitted. Bracket entrants, cross-thread open calls, overlapping/reentrant calls, unreadable/partial samples, invalid ticks, overflow or changed lifecycle make the packet terminally unusable. There is no waiting, guest-call serialization or lock held across the original.

At most 256 complete records are buffered; logs are emitted at successful close. Zero matching calls has an explicit installed/open/seal lifecycle. Outside-window calls after a successful close remain ordinary calls; an in-window call returning across close is rejected. Deferred records are checked against the exact separately parsed menu boundaries, thread and ordered ticks. A late unusable record invalidates an otherwise sealed packet. Samples remain non-atomic; atomic diagnostic admission is not a quiescence guarantee or proof of all global writers.

The parser reports observed vector gaps between begin, call-before/call-after and confirmation. `observed_chain_connected` means those observed endpoints connect; it never means complete-state or exhaustive consumer coverage. A valid zero-call packet with different begin/confirm vectors rejects helper-only attribution, rather than hiding the unobserved change. Fatal, sealed 500R/0S, original-reference, identity and origin/reset gates remain separate obligations.
